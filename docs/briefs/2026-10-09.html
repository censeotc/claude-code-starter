    Oct 09
    Why it matters
    v2.1.296 introduces code execution policy settings in Claude Desktop's managed policies array, enabling gateway mode configuration alongside desktop-based execution. This affects how enterprises configure code execution sandboxing and governance.
    Overview
    Claude Desktop version 2.1.296 was released on 2026-10-09 with updates to code policy configuration. A new 'code' key was added to the Claude apps gateway's managed.policies[] array, bringing the same settings available in the CLI to Claude Desktop's Code tab interface. Gateway mode activation is now available in addition to the existing desktop execution mode, allowing organizations to choose between local execution and gateway-mediated code execution. This change provides parity between CLI and desktop configuration options for code execution policies. The update maintains the same policy settings interface across multiple Claude interfaces, reducing configuration friction for enterprise deployments.
