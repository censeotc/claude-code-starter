  • v2.1.196ROUTINE
    Jun 29
    Why it matters
    This release adds administrative control over model defaults at the organization level, reducing friction for teams with standardized model preferences and improving the user experience for organizations without explicit model selection.
    Overview
    Version 2.1.196 introduces organization default models that admins can configure via the org console. When users haven't selected a specific model, the system displays 'Org default' or 'Role default' in the /model endpoint, indicating which default is active. The release also adds readable default names, improving clarity around which model variant is being used. This feature targets enterprise and team deployments where standardizing on specific models reduces configuration overhead and ensures consistent behavior across organization members.
