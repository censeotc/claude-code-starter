  • v2.1.288ROUTINE
    Oct 02
    Why it matters
    This version bump adds developer-facing utilities for text selection handling and GitHub API integration in cloud environments, expanding what integrations can accomplish without additional setup.
    Overview
    Version 2.1.288 introduces $.ui.selection() method that captures text selected in fullscreen mode and returns the containing transcript row when selection occurs within row boundaries. The release also adds a built-in GitHub API client for cloud sessions, eliminating the need for external authentication setup in cloud-hosted environments. These are incremental feature additions to the existing SDK rather than breaking changes or architectural shifts. The selection API enables more granular interaction tracking, while the gh api integration reduces friction for cloud-based workflows. No specific dates or deprecation notices are mentioned. This represents routine platform expansion for developers building on top of the system.
