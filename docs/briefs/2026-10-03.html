  • v2.1.289ROUTINE
    Oct 03
    Why it matters
    This patch addresses a permission enforcement gap where deny/ask rules weren't persisting across nested compound shell commands on managed machines, and resolves a terminal UI stability issue. These are operational fixes that affect managed deployment scenarios and developer experience with code execution.
    Overview
    Version 2.1.289 was released on 2026-10-03 with two primary fixes. The first addresses a bug where deny or ask rules applied to nested parts of compound shell commands were not properly holding over user-installed mod approvals on managed machines, which could create security or policy compliance issues. The second fix resolves terminal freezing that occurred when processing short code blocks containing many unclosed elements. The release represents incremental stability improvements rather than new functionality.
