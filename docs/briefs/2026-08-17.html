  • v2.1.234ROUTINE
    Aug 17
    Why it matters
    This version bump introduces a minor configuration flexibility feature that allows infrastructure operators to customize project directory naming, with no breaking changes or user-facing impact.
    Overview
    Version 2.1.234 released on 2026-08-17 adds an optional CLAUDE_CODE_PROJECT_DIR_NAME environment variable that enables hosts managing per-session configurations to specify a custom short name for per-project transcript directories. This allows infrastructure operators greater control over directory naming conventions without affecting core functionality. The feature is backward compatible and only applies to environments that opt into per-project configuration isolation. The change supports transcript organization across multi-tenant or multi-project hosting scenarios. No other modifications or breaking changes are included in this release.
