  • v2.1.294MINOR
    Oct 08
    Why it matters
    v2.1.294 fixes a critical security flaw where instruction-based prompt and agent hooks were failing to block commands they were designed to block, improving enforcement of security policies. This is important for users relying on hooks to control agent and command behavior.
    Overview
    Version 2.1.294 was released on 2026-10-08 with fixes to prompt and agent hook functionality. The release addressed a bug where prompt and agent hooks written as instructions (such as "Block commands that...") were incorrectly allowing actions they were intended to block. Additionally, improvements were made to how prompt hooks on Stop and SubagentStop events handle instruction-based rules. This fix ensures that instruction-based hook policies are now properly enforced to prevent unintended command execution.
