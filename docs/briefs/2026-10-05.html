  • v2.1.290MINOR
    Oct 05
    Why it matters
    Version 2.1.290 adds developer-facing observability features for tool usage tracking and agent identification, improving debugging and monitoring capabilities for integrations using the API.
    Overview
    v2.1.290 was released on October 5, 2026 with two key additions: serverToolUses was added to the result of a mod's turn.step hook, which returns tool calls made by the advisor with metadata including id, name, input, start time, and end time for each call; agentId was added to the tool.check event of a plugin to enable tracking which agent initiated tool checks. These changes enhance observability for developers building with the API by providing granular visibility into tool execution within agent workflows. The release does not indicate breaking changes or major feature additions, positioning it as an incremental update focused on developer instrumentation.
