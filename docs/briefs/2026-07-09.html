  • v2.1.206ROUTINE
    Jul 10
    Why it matters
    Version 2.1.206 adds developer convenience features for code navigation and repository hygiene, reducing manual workflow friction. These are targeted quality-of-life improvements for engineering teams using Claude in development contexts rather than core functionality changes.
    Overview
    Release v2.1.206 shipped on 2026-07-10 with three specific improvements: (1) Directory path suggestions added to the /cd command, now matching the behavior of /add-dir for consistency; (2) A new /doctor diagnostic check that identifies and proposes trimming checked-in CLAUDE.md files that contain content Claude could instead derive directly from the codebase; (3) Related enhancements to /commit command functionality. These changes focus on reducing redundant context and improving command usability in the Claude development tooling. The updates are backward compatible and target power users optimizing context window usage and repository cleanliness.
