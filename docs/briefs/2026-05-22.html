  • v2.1.149MINOR
    May 22
    Why it matters
    v2.1.149 introduces granular usage visibility and keyboard navigation improvements, helping users understand what drives their consumption limits and improving developer experience in detail views.
    Overview
    Version 2.1.149 released on 2026-05-22 includes two primary changes. The /usage endpoint now displays per-category breakdown of limit drivers, specifically showing costs broken down by skills, subagents, plugins, and per-MCP-server charges, replacing or supplementing prior aggregate usage display. The /diff detail view gained keyboard navigation support using arrow keys and j/k vim-style navigation, addressing a UX gap where keyboard-only navigation was previously unavailable. These changes improve observability into consumption patterns and developer workflow efficiency. The release is incremental (patch version bump from 2.1.148), indicating these are targeted improvements rather than breaking changes.
