  • v2.1.246ROUTINE
    Aug 25
    Why it matters
    This patch refines security warnings and UI organization for permission management. PMs should note improved developer feedback on wildcard Bash rules and new Auto mode visibility.
    Overview
    v2.1.246 introduces a startup warning system that flags Bash allow rules using wildcard patterns before subcommands (e.g., Bash(git * main)), alerting users that such rules also match options inserted before the subcommand, which could expand permissions unintentionally. The release adds an Auto mode tab to the permissions interface, improving discoverability and organization of permission management features. The changes target developer experience by surfacing potential security configuration issues earlier in the workflow. No breaking changes or API modifications are indicated. This is a routine version bump focused on validation feedback and UI enhancement.
